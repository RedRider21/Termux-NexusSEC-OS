>_ Termux-NexusSEC-OS
Ambiente di pentesting su Android · senza root
⚠️ Non installare Termux dal Play Store: quella versione è vecchia e non aggiornabile. Usa una delle fonti ufficiali qui sotto.

1 Scarica Termux

🔑 Regola d'oro: installa Termux e i suoi add-on (Termux:Boot, Termux:API) dalla stessa fonte. Le app Termux si scambiano i permessi in base alla firma: se mescoli F-Droid e GitHub, gli add-on non funzioneranno. Il modo più semplice e sicuro è prendere tutto da F-Droid.

Modo consigliato — F-Droid. Si aggiorna da solo e sceglie in automatico l'APK giusto per il tuo telefono.

🟢 Termux su F-Droidapri e premi "Scarica APK" (richiede l'app F-Droid o il download diretto) CONSIGLIATO

In alternativa — APK ufficiale da GitHub (release v0.118.3). Scegli l'architettura del tuo telefono: quasi tutti i modelli dal 2017 sono arm64-v8a. Se non sei sicuro, usa universal (va bene ovunque, ma pesa di più).

📱 arm64-v8ala scelta giusta per la maggior parte dei telefoni GIUSTO PER TE?
🌍universalva ovunque (~118 MB) 📟armeabi-v7atelefoni vecchi 32-bit 💻x86_64emulatore / tablet Intel 💻x86emulatore 32-bit

Vuoi sempre l'ultima versione? Release più recente su GitHub. Dopo il download, Android chiederà di consentire l'installazione da "origini sconosciute": accetta.

2 Installa NexusSEC-OS

Modo facile — una riga sola. Apri Termux appena installato e incolla questa (tieni premuto per incollare): fa tutto e avvia l'app.

pkg install -y curl && curl -fsSL https://raw.githubusercontent.com/RedRider21/Termux-NexusSEC-OS/master/nexussec-setup.sh | bash

Poi apri http://127.0.0.1:8000 nel browser. Scarica ~700 MB–1 GB (tool + Debian minimale): meglio sotto Wi-Fi.

Modo manuale (se preferisci vedere ogni passaggio):

pkg update -y && pkg upgrade -y
termux-setup-storage
pkg install -y git python
git clone https://github.com/RedRider21/Termux-NexusSEC-OS.git
cd Termux-NexusSEC-OS
bash install.sh
python server.py

3 Comodità (opzionale)

Avvio automatico all'accensione. Installa Termux:Boot: poi dall'app NexusSEC (menu → Manutenzione → Abilita autostart) il server partirà da solo. Utile anche Termux:API.

🚀Termux:Bootavvia il server all'accensione (F-Droid) 🔌Termux:APInotifiche, appunti, apri-URL… (F-Droid)

⚠️ Questi add-on sono su F-Droid: usali solo se hai installato anche Termux da F-Droid. Se hai preso Termux dall'APK GitHub, scarica gli add-on dalle release GitHub (termux-boot, termux-api) così le firme combaciano.

L'interfaccia si apre nel browser del telefono. Puoi anche aggiungerla alla schermata Home per usarla a schermo intero come un'app.

4 Aggiornare e lingua

Aggiornamenti dall'app, senza comandi. Quando esce una versione nuova, appare un pallino arancione ● sul pulsante ☰ NexusSEC: apri ☰ → Manutenzione → ⬇ Aggiorna app, guarda il flusso live con il resoconto, poi parte da sola ⏻ Riavvia server e la pagina si ricarica.

🌐 Italiano / English. L'app è tutta localizzata (interfaccia, tool, messaggi e procedure). Si cambia da ☰ → Sistema → 🌐 con una combobox.
